# 🧠 Ta Te Ti en Python

Este es un sencillo juego de **Ta Te Ti (Tres en línea)** desarrollado en **Python**, como parte de mis prácticas de programación.

## 🎮 Cómo jugar

1. Ejecutá el programa con:
   ```bash
   python3 tateti.py

2. Seguí las instrucciones que aparecen en la consola
3. Dos jugadores se alternan para colocar sus fichas (X, O) en un tablero 3x3
4. El juegoo detecta automáticamente si hay un ganador o si hay empate.

## Requisitos

-Python 3.8 o superior
-No requiere librerías externas

## How to play

1. Execute the program with:
   ```bash
   python3 tateti.py
